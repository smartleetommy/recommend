# Recommend

一个基于 React + Vite 的网页版待办事项提醒工具。

## 功能

- 新增、完成、删除待办事项
- 设置优先级和截止时间
- 支持按状态和关键词筛选
- 支持浏览器通知提醒
- 使用 `localStorage` 保存本地数据

## 技术栈

- React 18
- Vite 5
- 原生 CSS

## 本地启动

```bash
npm install
npm run dev
```

默认访问地址：

```text
http://localhost:4173
```

## 打包

```bash
npm run build
```

打包产物会输出到 `dist/` 目录。

## 提醒权限说明

页面中的通知权限状态含义如下：

- `已允许`：浏览器已允许发送通知
- `已拒绝`：浏览器已拒绝发送通知
- `未设置`：还没有选择是否允许通知
- `当前浏览器不支持`：当前环境无法使用通知 API
